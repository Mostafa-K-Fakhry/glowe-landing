# Glowé — Premium Skincare Landing Page

A modern, responsive, and interactive skincare landing page for **Glowé**, a premium Vitamin C Serum brand.

The project combines a premium visual experience with interactive e-commerce functionality using HTML, CSS, Bootstrap, and JavaScript.

## About The Project

Glowé is a premium skincare landing page designed to present and promote a Vitamin C Serum through a modern and visually engaging e-commerce experience.

The website focuses on:

- Premium product presentation
- Clear product benefits
- Ingredient storytelling
- Customer reviews
- Product purchasing experience
- Responsive design
- Interactive UI components
- Conversion-focused sections

The project was initially created as a UI concept and then developed into a structured front-end project using **HTML5, CSS3, Bootstrap 5, and Vanilla JavaScript**.

---

## Features

### Responsive Design

The website is fully responsive and optimized for:

- Desktop
- Laptop
- Tablet
- Mobile devices

The layout adapts across different screen sizes while maintaining the same visual identity and user experience.

---

### Hero Section

The Hero section introduces the Glowé Vitamin C Serum with:

- Premium product photography
- Main marketing headline
- Product description
- Key product benefits
- Primary call-to-action
- Customer social proof
- High-quality product presentation

The product photography is integrated into the Hero composition to create a stronger visual connection between the product and the page background.

---

### Product Benefits

The website highlights the main benefits of the Glowé Vitamin C Serum:

- Brightens Skin
- Deep Hydration
- Antioxidant Protection

---

### Brand Story

A dedicated brand section introduces Glowé and communicates the brand's skincare philosophy through a clean editorial layout and product-focused imagery.

---

### Ingredients

The product's key ingredients are presented in a dedicated section:

- Vitamin C
- Hyaluronic Acid
- Niacinamide

Each ingredient is presented with supporting information to help users understand the product formula.

---

### How It Works

The website explains the recommended skincare routine through three simple steps:

1. Apply 2–3 drops to clean, dry skin.
2. Gently massage until fully absorbed.
3. Use consistently for best results.

---

### Customer Reviews

The project includes a customer testimonial section with:

- Customer reviews
- Star ratings
- Customer profiles
- Review navigation

The reviews section is horizontally scrollable and includes navigation controls.

---

### Product Purchase Section

The product purchase area provides a complete front-end shopping experience including:

- Product information
- Current price
- Original price
- Discount
- Product rating
- Quantity selector
- Add to Cart button
- Buy Now button
- Secure payment information
- Shipping information
- 30-day guarantee

---

### Shopping Cart

The cart functionality is implemented using Vanilla JavaScript.

Users can:

- Increase product quantity
- Decrease product quantity
- Add products to the cart
- View the current cart count
- Persist cart data using `localStorage`

---

### FAQ Accordion

The FAQ section provides an interactive accordion experience.

Users can expand and collapse questions without reloading the page.

---

### Mobile Navigation

A responsive mobile navigation menu is implemented for smaller screen sizes.

Users can:

- Open the mobile menu
- Close the mobile menu
- Navigate between sections
- Automatically close the menu after selecting a section

---

### Newsletter Subscription

The footer includes a newsletter subscription form with client-side validation and interactive feedback.

---

### Toast Notifications

Custom toast notifications provide visual feedback for important user interactions.

Examples include:

- Product added to cart
- Cart status
- Newsletter subscription
- Checkout interaction

---

## Technologies Used
